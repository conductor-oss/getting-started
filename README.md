# Conductor OSS — Getting Started

This repo tracks issues with the Conductor OSS new-user experience: documentation, quickstart guides, and the install/setup flow.

## Found a problem?

If something in the [quickstart](https://docs.conductor-oss.org/quickstart/) is broken, confusing, or missing — **[open an issue here](https://github.com/conductor-oss/getting-started/issues/new)**. This is the right place even if you're not sure which repo the fix belongs in.

## Open issues

See the [issue tracker](https://github.com/conductor-oss/getting-started/issues).

## Fixes live in

- [`conductor-oss/conductor`](https://github.com/conductor-oss/conductor) — README, docs, quickstart
- [`conductor-oss/conductor-cli`](https://github.com/conductor-oss/conductor-cli) — CLI behavior
- SDK repos — [`java-sdk`](https://github.com/conductor-oss/java-sdk), [`python-sdk`](https://github.com/conductor-oss/python-sdk), [`javascript-sdk`](https://github.com/conductor-oss/javascript-sdk), etc.
